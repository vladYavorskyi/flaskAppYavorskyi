# Flask Hotel Management & User System

Навчальний веб-додаток на базі фреймворку Flask, що реалізує повноцінну систему керування користувачами та функціонал для адміністрування готельних номерів.

## Функціонал:

### Система користувачів
*   **Авторизація та реєстрація**: Безпечний вхід та вихід із системи.
*   **Особистий кабінет**: Відображення даних профілю, дати реєстрації та останньої активності.
*   **Редагування профілю**: Можливість змінювати юзернейм, інформацію "про себе" та завантажувати власну аватарку.
*   **Керування сесіями та Cookie**: Реалізовано функціонал перегляду, додавання та видалення файлів Cookie прямо через інтерфейс.

### Керування номерами (Hotel Rooms)
*   **Dashboard номерів**: Перегляд списку доступних номерів з фільтрацією за типом та ціною.
*   **CRUD операції**: Створення, редагування та видалення інформації про готельні номери (опис, місткість, ціна, статус доступності).
*   **Зручний інтерфейс**: Використання сучасних форм для редагування параметрів номерів.

## Технологічний стек
*   **Core:** Python, Flask
*   **Frontend:** Jinja2 templates, HTML5, CSS3, Bootstrap
*   **Database:** SQLAlchemy (SQLite/PostgreSQL)
*   **DevOps:** Docker, Docker Compose
*   **Tools:** Flask-Login (для сесій), Pillow (для обробки зображень профілю)
